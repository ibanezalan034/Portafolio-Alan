### Detalle de cada desarrollo

* **Sistema de Gestión Comercial (`./proyectos/sistema-gestion-comercial`)**
  Aplicación de escritorio estructurada en capas (*presentación, lógica y datos*) para la administración de operaciones comerciales, control de comprobantes, cotejo de compras, gestión de proveedores y emisión de notas de crédito y débito mediante *stored procedures* en SQL Server.

* **NeoCommerce (`./proyectos/neocommerce`)**
  Aplicación web full-stack con flujo de autenticación y gestión de sesiones, conexión a base de datos relacional, catálogo dinámico e interfaz adaptable a distintos dispositivos.

* **Portal de Mundiales (`./proyectos/portal-mundiales`)**
  Sitio web interactivo dedicado a la organización y consulta de información histórica sobre los campeonatos mundiales de fútbol, con manipulación dinámica del DOM y diseño *responsive*.
